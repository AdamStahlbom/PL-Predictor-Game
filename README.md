# Premier League Tipping Platform ⚽

En fullstack tipssida för kompisgänget byggd med Next.js, TypeScript, Tailwind CSS och Supabase.

## 🛠️ Tech Stack

- **Frontend/Backend:** Next.js (App Router), TypeScript, Tailwind CSS
- **Databas & Auth:** Supabase (PostgreSQL, Row-Level Security, Google OAuth)
- **Hosting:** Vercel (med Vercel Crons)
- **Data Source:** API-Football

## 🚀 Funktioner (Work in Progress)

- [ ] Google-inloggning via Supabase Auth
- [ ] Veckovis tipping av Premier League-matcher
- [ ] Automatisk resultathämtning & poängberäkning
- [ ] Head-to-Head statistik, formkurvor och odds per match
